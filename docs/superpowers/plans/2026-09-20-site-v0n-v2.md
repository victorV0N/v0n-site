# Site da v0n v2 — Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refazer a home da v0n na direção v2 — raio no lugar do chanfro, título condensado, movimento em toda seção, Diagnóstico e FAQ — e terminar o que ficou: molde de case, metadados e verificação.

**Architecture:** O site continua sendo `index.html` + `css/site.css`, sem build e sem dependência. O que muda de estrutura é um arquivo novo: `js/site.js`, com `defer`, onde vive o menu (que hoje está inline no fim do HTML), o `IntersectionObserver` da entrada por rolagem e o Diagnóstico. A entrada por rolagem é `transition` + uma classe, não `@keyframes`: uma classe de estado inicial no HTML, a classe `.visivel` acrescentada pelo observer, e o navegador interpola. Sem JS, o CSS entrega tudo visível.

**Tech Stack:** HTML5, CSS3 (custom properties, grid, clamp, `transition`), JavaScript de baunilha (~90 linhas em `js/site.js`), Google Fonts (Barlow Condensed + Space Grotesk + IBM Plex Mono), Netlify. Node só pro `dev.js` e pra medição; não vai pro ar.

**Spec:** `docs/superpowers/specs/2026-09-20-site-v0n-design.md` (v2, commit `d84c5c6`) — **autoridade vinculante.** O plano argumenta a partir dele; leia os dois.

**Ponto de partida:** branch `site`, HEAD `5aba7ea`. A home tem 5 seções visíveis (hero, `01 / O QUE TRAVA`, `02 / MÉTODO`, `04 / SERVIÇOS`, `05 / QUEM FAZ`), fecho e rodapé, e a seção `03 / TRABALHOS` comentada esperando material. `css/site.css` tem 309 linhas, `index.html` tem 197.

## Global Constraints

Valem em toda tarefa. Valores copiados do spec, não reescritos de memória.

- **Cores, e só elas:** carbono `#121317` · grafite `#1B1D23` · linha `#2A2D35` · aço `#8C96A3` · osso `#ECEDE8` · ouro `#FFC531` · verde-ok `#3FBF7F`.
- **Azul é proibido**, inclusive o azul de link padrão do navegador.
- **Proporção 70% carbono · 20% neutro · 10% ouro.**
- **Um botão ouro por tela**, três na página inteira: topo (só desktop), Diagnóstico (só depois das três respostas) e fecho. Nunca na mesma dobra. CTA intermediária é de traço.
- **Raio, não chanfro.** `--raio:14px` em cartão, painel e campo · `--raio-g:24px` em bloco grande · `--raio-p:999px` em botão. **Nenhum `clip-path` de chanfro sobrevive** ao fim da Tarefa 4.
- **Tipografia:** Barlow Condensed 200 (300 abaixo de 600px) caixa alta no título grande · Space Grotesk 700 em nome de card, 400/500 no corpo · IBM Plex Mono 500 caixa alta 12–13px com tracking +9% em etiqueta, número e menu. **Três famílias é o teto.**
- **Neon (`text-shadow`) só em número e ouro.** Título e texto corrido ficam limpos.
- **Orçamento de movimento, e é lei:** só `transform` e `opacity` animam (a exceção é o `clip-path` da variante abre-por-corte, composto na GPU). Nenhum `@keyframes` infinito, exceto o pulso do estado ativo do Diagnóstico. Sem partícula, meteoro, orbe ou 3D. Nada anima antes de estar na tela; nada anima duas vezes. Sem JS, tudo aparece pronto.
- **Sem framework, sem bundler, sem `node_modules`, sem biblioteca de animação.**
- **Desenhado a partir de 360px.** Nenhuma rolagem horizontal em nenhuma largura.
- **Contraste AA medido**, não presumido.
- **`prefers-reduced-motion: reduce` zera animação e transição** e deixa tudo legível.
- **Tom:** direto e curto, de humano pra humano. Proibido: tom de guru, "alavancar", "destravar seu potencial", gatilho de escassez, emoji em texto sério.
- **Sem preço. Sem número inventado. Sem case inventado.** CTA sempre WhatsApp.
- **Marcas que travam a publicação:** `contato-pendente` (número real), `resposta-pendente` (respostas do FAQ que são fato do negócio do Kauã), `SEU-SITE` (domínio). Nenhuma pode sobrar na Tarefa 9.

- [ ] **Step 1: Criar `js/site.js` com o menu que já existia e o observer novo**

O menu sai de dentro do HTML sem mudar de comportamento. O observer é código novo.

```js
// JS do site da v0n. Sem dependencia, sem build.
// A linha que poe a classe `js` no <html> fica inline no <head>: ela precisa
// rodar antes do CSS pintar, senao o menu pisca aberto no carregamento.
(function () {
  'use strict'

  // ---- Menu do celular -------------------------------------------------
  var alterna = document.querySelector('.topo__alterna')
  var topo = document.querySelector('.topo')

  if (alterna && topo) {
    alterna.addEventListener('click', function () {
      var aberto = topo.classList.toggle('menu-aberto')
      alterna.setAttribute('aria-expanded', aberto)
      alterna.setAttribute('aria-label', aberto ? 'Fechar menu' : 'Abrir menu')
    })
  }

  // ---- Entrada por rolagem ---------------------------------------------
  // Um observer pra pagina inteira. Cada alvo entra uma vez e para de ser
  // observado: nada anima duas vezes, e o observer se esvazia sozinho.
  var alvos = document.querySelectorAll('.entra, .entra-fade, .entra-corte')

  if ('IntersectionObserver' in window) {
    var observer = new IntersectionObserver(function (entradas) {
      entradas.forEach(function (entrada) {
        if (!entrada.isIntersecting) return
        entrada.target.classList.add('visivel')
        observer.unobserve(entrada.target)
      })
    }, {
      // -12% no rodape: o elemento comeca a entrar um pouco depois de
      // aparecer, senao a animacao termina antes de a pessoa ter olhado.
      rootMargin: '0px 0px -12% 0px',
      threshold: 0.1
    })
    alvos.forEach(function (alvo) { observer.observe(alvo) })
  } else {
    // Navegador antigo ve a pagina montada, sem entrada. Nao e erro: a
    // entrada e enfeite, nunca condicao pra ler.
    for (var i = 0; i < alvos.length; i++) alvos[i].classList.add('visivel')
  }

  // A Tarefa 4 acrescenta o Diagnostico aqui, antes do fecho do IIFE.
})()
```

- [ ] **Step 3: Escrever as três variantes de entrada no CSS**

No fim de `css/site.css`:

```css
/* ---------- Entrada por rolagem -------------------------------------
   Estado inicial na classe, estado final em .visivel, e o navegador
   interpola. Sem @keyframes: transition e mais barata e nao precisa de
   nome. So transform e opacity animam - clip-path na variante de corte
   e a excecao medida do spec, composta na GPU.
   A cascata e --i no CSS, nunca setTimeout no JS. */
.entra, .entra-fade, .entra-corte{
  transition-duration:var(--entra);
  transition-timing-function:var(--saida);
  transition-delay:calc(var(--i, 0) * 80ms);
}
.entra{opacity:0; transform:translateY(18px); transition-property:opacity, transform}
.entra-fade{opacity:0; transition-property:opacity}
.entra-corte{clip-path:inset(0 100% 0 0); transition-property:clip-path}

.entra.visivel, .entra-fade.visivel{opacity:1; transform:none}
.entra-corte.visivel{clip-path:inset(0 0 0 0)}

/* Sem JS, nada fica escondido esperando uma classe que nunca vem. */
html:not(.js) .entra,
html:not(.js) .entra-fade,
html:not(.js) .entra-corte{opacity:1; transform:none; clip-path:none}
```

- [ ] **Step 4: Blindar o `prefers-reduced-motion`**

O bloco que já existe (linhas 43–45) zera `animation` e `transition` com `!important`. Isso por si só já resolve — a classe `.visivel` continua sendo posta pelo JS e o estado final se aplica na hora, sem interpolação. **Mas se o JS falhar em quem pediu menos movimento, a pessoa fica com a página em branco.** Uma linha resolve. }

```js
  // ---- 01 / Diagnostico -------------------------------------------------
  // Estado so na memoria: sem localStorage, sem cookie, sem servidor. O
  // laudo vive enquanto a aba vive. E diagnostico, nao cadastro - cadastro
  // pediria aviso de privacidade que o spec nao tem.
  var LAUDO = [
    { nao: 'Quem procura o que você faz acha o concorrente, não você.',
      sim: 'Você já aparece no Google.',
      queixa: 'não apareço no Google' },
    { nao: 'Você não tem um lugar seu na internet — só o perfil que a rede te empresta.',
      sim: 'Você tem site.',
      queixa: 'não tenho site' },
    { nao: 'Quem te acha desiste antes de conseguir te chamar.',
      sim: 'Quem te acha te chama em um toque.',
      queixa: 'quem me acha não consegue me chamar no WhatsApp' }
  ]

  var WPP = '#contato-pendente' // trocar pelo https://wa.me/NUMERO?text= real
  var respostas = [null, null, null]
  var opcoes = document.querySelectorAll('.diag__opcao')
  var laudo = document.getElementById('diag-laudo')
  var cta = document.getElementById('diag-cta')

  function mensagem() {
    var queixas = []
    for (var i = 0; i < 3; i++) {
      if (respostas[i] === 'nao') queixas.push(LAUDO[i].queixa)
    }
    if (!queixas.length) {
      return 'Oi! Vim pelo site. Tenho site, apareço no Google e recebo no ' +
             'WhatsApp — quero achar o que ainda está travando.'
    }
    return 'Oi! Vim pelo site. Meu caso: ' + queixas.join('; ') + '.'
  }

  function desenhaLaudo() {
    laudo.textContent = ''
    for (var i = 0; i < 3; i++) {
      if (respostas[i] === null) continue
      var p = document.createElement('p')
      p.textContent = LAUDO[i][respostas[i]]
      laudo.appendChild(p)
    }

    var completo = respostas.indexOf(null) === -1
    if (!completo) return

    var tudoOk = respostas.every(function (r) { return r === 'sim' })
    var fecho = document.createElement('p')
    fecho.textContent = tudoOk
      ? 'O básico está de pé. Nesse caso o gargalo é outro — e achar isso é o que eu faço.'
      : 'É isso que trava. Me chama que eu te mostro funcionando antes de falar de valor.'
    laudo.appendChild(fecho)

    // O ouro do Diagnostico so existe depois das tres respostas: e o ouro
    // que paga a interacao, e antes disso a CTA e de traco.
    cta.classList.add('btn--ouro')
    cta.textContent = tudoOk ? 'Me chama que eu olho' : 'Chamar no WhatsApp'
    cta.href = WPP === '#contato-pendente'
      ? '#contato-pendente'
      : WPP + encodeURIComponent(mensagem())
  }

  for (var o = 0; o < opcoes.length; o++) {
    opcoes[o].addEventListener('click', function () {
      var p = Number(this.dataset.p)
      respostas[p] = this.dataset.r
      var irmas = this.parentNode.querySelectorAll('.diag__opcao')
      for (var k = 0; k < irmas.length; k++) {
        irmas[k].setAttribute('aria-pressed', String(irmas[k] === this))
      }
      desenhaLaudo()
    })
  }
```

**Quem responde "sim" nas três não é mandado embora** — é justamente quem mais paga. O laudo diz que o básico está de pé e a CTA muda de texto.
