**Goal:** Colocar no ar o site da v0n — uma home que serve os três públicos e um molde de página de case que cresce sem refazer nada.

**Architecture:** HTML e CSS escritos na mão, sem framework e sem build. Um `index.html` com oito seções, um `css/site.css` com os tokens da identidade, e `cases/<negocio>.html` clonado a partir de um molde. JavaScript só no menu do celular, inline. Publicação por push na Netlify.

**Tech Stack:** HTML5, CSS3 (custom properties, grid, clamp), JavaScript de baunilha (menos de 20 linhas), Google Fonts (Space Grotesk + IBM Plex Mono), Netlify.

**Spec:** `docs/superpowers/specs/2026-09-20-site-v0n-design.md`

## Global Constraints

Valem em toda tarefa. Fonte: `MazyOS/identidade/design-guide.md` e `MazyOS/_memoria/preferencias.md`.

- **Produção visual passa pela skill `impeccable`** — carregue antes de escrever interface (Tarefa 2 em diante). Ela executa dentro do design-guide, nunca por cima dele.
- **Cores, e só elas:** carbono `#121317` · grafite `#1B1D23` · linha `#2A2D35` · aço `#8C96A3` · osso `#ECEDE8` · ouro `#FFC531` · verde-ok `#3FBF7F`.
- **Azul é proibido.** Inclui azul de link padrão do navegador.
- **Proporção 70% carbono · 20% neutro · 10% ouro.** Ouro acima de um décimo da tela vira ruído.
- **Um botão ouro por tela.** O do topo e o do fecho nunca aparecem juntos na mesma rolagem; CTA intermediária é de traço.
- **Tipografia:** Space Grotesk (título 700, corpo 400/500) e IBM Plex Mono (etiqueta, número, menu — caixa alta, letter-spacing +9%, 12–14px).
- **Neon só em título e número**, via `text-shadow`. Texto corrido e rótulo ficam limpos.
- **Traço grosso, cortes de 45°.** Nenhuma curva onde cabe um chanfro.
- **Sem framework, sem bundler, sem `node_modules`.** Nada entre salvar o arquivo e ver a mudança.
- **Desenhado a partir de 360px de largura.** Nenhuma rolagem horizontal em nenhuma largura.
- **Contraste AA medido**, não presumido.
- **Toda imagem em WebP, com `width` e `height` no HTML.** Sem as dimensões a página pula quando a imagem carrega — e quem está no 4G vê o salto.
- **Direção visual: estilo do Hermes, cor da v0n** (spec, seção "Direção visual"). Etiqueta mono em caixa alta em toda seção; seção numerada e nomeada (`01 / O QUE TRAVA`); régua de 1px `--linha` como único ornamento, com o rótulo encostado nela; painel de moldura dura com chanfro de 45°, sem sombra e sem gradiente; bloco denso tipo ficha (par rótulo → valor em mono) no lugar de parágrafo quando a informação for enumerável; título grande com tracking negativo e muito respiro. **A cor não vem da referência** — paleta da v0n, azul proibido. **Duas famílias, não três.**
- **Tom:** direto e curto, de humano pra humano. Proibido: tom de guru, "alavancar", "destravar seu potencial", persona genérica, gatilho de escassez, emoji em texto sério.
- **Sem preço no site. Sem número inventado.** CTA sempre WhatsApp.

- [ ] **Step 2: Medir o contraste do aço antes de usar**

O spec manda medir, não presumir. Rode:

```bash
node -e "
const lum = (hex) => {
  const c = [1,3,5].map(i => parseInt(hex.slice(i, i+2), 16) / 255)
    .map(v => v <= 0.03928 ? v/12.92 : Math.pow((v+0.055)/1.055, 2.4))
  return 0.2126*c[0] + 0.7152*c[1] + 0.0722*c[2]
}
const razao = (a, b) => {
  const [x, y] = [lum(a), lum(b)].sort((p, q) => q - p)
  return ((x + 0.05) / (y + 0.05)).toFixed(2)
}
for (const [nome, cor] of [['aco','#8C96A3'],['osso','#ECEDE8'],['ouro','#FFC531'],['sucesso','#3FBF7F']]) {
  console.log(nome + ' sobre carbono: ' + razao(cor, '#121317') + ':1')
}
console.log('carbono sobre ouro (botao): ' + razao('#121317', '#FFC531') + ':1')
"
```

Expected: cada linha mostra a razão. **Regra de decisão:** texto corrido precisa de 4.5:1; título grande (24px+ em 700) precisa de 3:1. Se o aço ficar abaixo de 4.5:1, clareie até passar e registre o novo valor como `--aco` **no site** — o design-guide continua valendo pra peça gráfica, conforme o spec.
